# Quality gate

`bun run check` must pass before a push and in CI. It runs, in order:

| Step         | Command                     | Enforces                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------ | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Types        | `bun run typecheck`         | `tsconfig.json`: `strict` plus `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`, `noPropertyAccessFromIndexSignature`, `erasableSyntaxOnly`, no unused locals/parameters, no unreachable code.                                                                                                                                                                                                                                                                                                                                          |
| Lint         | `bun run lint`              | `.oxlintrc.json`, type-aware: the correctness, suspicious, pedantic and perf categories as errors; no `as` casts (except `as const`), no `!`, no `any`; explicit return types; no import cycles; no size or complexity limits (function shape is a review call, `CODING_STANDARDS.md`); and the bans from `CODING_STANDARDS.md` (`Math.random`, wall-clock timing and browser globals in game code, `fillText`). `scripts/lint-guards.ts` rejects `oxlint-disable`/`eslint-disable` and `@ts-ignore`/`@ts-expect-error`/`@ts-nocheck` comments. |
| Format       | `bun run format:check`      | Prettier, `printWidth` 120. `bun run format` fixes it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Unused code  | `bun run knip`              | No unused files, exports or dependencies. Mark deliberately kept exports with `/** @public */`.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Tests, build | `bun test`, `bun run build` | As before.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

The pre-commit hook formats and lint-fixes the staged files, so most issues are fixed before they reach the gate.

## Fix the code, not the rules

There are no escape hatches: a finding is fixed in the code. Replace a cast with a type guard, a `!` with a check that throws. If a rule is wrong for this repo, tell the owner; the owner changes the config.

The gate's own files (`tsconfig.json`, `.oxlintrc.json`, Prettier and knip config, `package.json`, `scripts/lint-guards.ts`, `.githooks/`, `.github/`, `CODING_STANDARDS.md` and this page): change them only when the owner asks for it.
