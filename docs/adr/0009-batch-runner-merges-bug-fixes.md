# The Sandcastle batch runner merges bug fixes

An exception to ADR 0007. `bun run sandcastle:batch` (`.sandcastle/batch.ts`) merges a pull request itself, with `gh pr merge --squash`, when all of these hold: the issue is labelled `bug` and `ready-for-agent`, the pipeline's `bun run check` ended green (so the PR is not a draft), and every CI check on the PR passed on the commit being merged (`--match-head-commit`). Bug fixes are small and many, and waiting on a review for each held the queue up; every other PR the batch opens, and everything other agents do, still waits for the owner to merge. Bugs run one at a time, each cut from a freshly fetched `origin/main` after the previous bug merged, so they never conflict with one another. A bug whose check or CI is red, or whose merge GitHub refuses, is left as an open PR for the owner.
